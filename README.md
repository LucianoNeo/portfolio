# Luciano Neo — C# / .NET portfolio

Portfólio em português e inglês, com experiência profissional, formação e projetos selecionados. O visual tem referências aos menus de RPGs eletrônicos.

## Site

[Portfólio publicado no GitHub Pages](https://lucianoneo.github.io/portfolio/)

HTML, CSS e JavaScript, sem dependências de build. O workflow `pages.yml` publica os arquivos estáticos. O resumo profissional em `resume.html` pode ser impresso em PT ou EN.

## Projetos selecionados

| Projeto | O que mostra |
| --- | --- |
| [NeoTasks · React + .NET](projects/neotasks-dotnet/README.md) | Interface React integrada à API .NET, PostgreSQL, autenticação, tarefas, horas e Docker Compose |
